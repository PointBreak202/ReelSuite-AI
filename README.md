# 🎬 ReelSuite AI

ReelSuite AI is an AI-powered reel generator built using Flask, FFmpeg, ElevenLabs, HTML, and CSS. It converts images and a script into an automatically narrated short-form video reel.

---

## ✨ Features

- Upload multiple images
- Add a custom narration script
- AI voice generation using ElevenLabs
- Automatic reel generation
- Simple and clean web interface

---

## 🛠️ Tech Stack

- Python
- Flask
- FFmpeg
- ElevenLabs API
- HTML
- CSS

---

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/PointBreak202/ReelSuite-AI.git
```

### 2. Open the project folder

```bash
cd ReelSuite-AI
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Flask app

```bash
python app.py
```
